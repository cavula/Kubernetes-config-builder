# v0.2.0

- **Three-step layout.** Choose a preset, customize settings if needed, then deploy. The Deploy step shows the command for the selected template and offers a Helm-to-YAML comparison.
- **Prometheus presets.** Minimal starts with the server alone, Recommended adds Alertmanager, kube-state-metrics, and node exporter, and Full chart defaults includes Pushgateway as well. Each add-on can be toggled separately. Argo CD starts from its chart defaults.
- **Learning and Compact modes.** Learning is the default and explains key YAML blocks in plain English. Compact keeps component and purpose headers along with deployment and safety instructions. Minimal Prometheus Learning YAML is 650 lines, down from 856.
- **Explained exports.** Copy and Download produce the same YAML with install and after-install instructions. Preview sections are collapsible, and the component list jumps to each section.
- **Offline Helm bundle.** Helm chart + values downloads a ZIP with the verified pinned chart archive, commented values, and a README with the exact local install command. Helm can use the bundle without a chart repository. The cluster still needs access to the container images or must already have them.

Run `docker compose up --build` from the extracted release and open [localhost:8080](http://localhost:8080).
