# v0.3.0

**Use the tool** is now the default view. Pick a template, customize its example-backed fields, then copy or download the generated YAML. Learning mode explains every YAML line.

- **Argo CD** includes Application, AppProject, and ApplicationSet templates, validated against the CRD schemas from the pinned chart. The Guestbook example explains how its AMD64-only image runs under emulation on ARM64 hosts such as Apple Silicon Macs.
- **Standalone Prometheus** includes an annotated metrics Service, a custom scrape job, and an alert rule. The Service uses Kubernetes schema validation. The scrape and alert templates export Helm values with upgrade commands pinned to chart 29.45.1, and promtool checks the rendered configuration and rules.
- **Install the tool** is a secondary option with the existing presets, Kubernetes manifest exports, and offline Helm bundles.

K3s checks verified Guestbook synchronization and health, ApplicationSet generation, both Prometheus scrape targets, and a firing alert after a failed scrape.

To run locally, download the release’s `compose.yaml`, run `docker compose up -d` from its folder, and open [localhost:8080](http://localhost:8080).
