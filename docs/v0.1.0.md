# v0.1.0

The first release of Kubernetes Config Builder and Learning Dashboard runs locally with Docker Compose.

- Build configurations for Prometheus 29.45.1 and Argo CD 10.17.1 on K3s with Kubernetes 1.35, 1.36, or 1.37.
- Edit chart settings and inspect live YAML and Helm values, field explanations, and a side-by-side comparison.
- Run Helm lint and schema validation locally. Copy or download the active format.
- Start with `docker compose up --build` from the extracted release and open [http://localhost:8080](http://localhost:8080). The first build downloads the pinned inputs and verifies the charts and schemas. The resulting image includes the dashboard, charts, schemas, and validators.

Argo CD manifest exports include the Redis initialization resources and instructions for server-side apply. Upstream chart image findings are tracked in [accepted risks](https://github.com/cavula/Kubernetes-config-builder/blob/v0.1.0/security/accepted-risks.json).
