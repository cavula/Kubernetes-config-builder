# v0.3.1

The dashboard now ships prebuilt Linux AMD64 and ARM64 images through GitHub Container Registry. Release CI builds and scans both architectures and verifies the dashboard and offline validators. The image includes the patched promtool and checksum-verified charts and schemas.

Download `compose.yaml` from this release, run `docker compose up -d` from its folder, and open [localhost:8080](http://localhost:8080). Developers can still build from a checkout with `docker compose -f compose.yaml -f compose.build.yaml up -d --build`.
